# homebrew-tap

Homebrew tap for [Tone Architect](https://github.com/memogonzalezj-dev/ToneArchitect) — AI-powered guitar preset generator for Line 6 HX devices.

## Install

```bash
brew tap memogonzalezj-dev/tap
brew install --cask tone-architect
```

## Requirements

- Apple Silicon Mac (M1 or later)
- macOS 12 Monterey or later
- ~6 GB free disk space (for the AI model download on first launch)
